# Data

A small made-up café, written for this notebook: twelve orders on four days in weeks 38 and
39 of 2026, kept in the tables a café's database would keep.

| File | One row is | Rows |
|---|---|--:|
| `orders.csv` | an order: `id`, `date`, `time`, `table`, and the loyalty `card`, empty for a guest without one | 12 |
| `items.csv` | a dish in an order: `order_id`, `dish`, `qty` | 20 |
| `prices.csv` | the `price` of a dish in a `week`, in hryvnias | 11 |

Free to use for any purpose.
